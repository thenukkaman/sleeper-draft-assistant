# Value, Tags, VBD, and Runs

The source board remains the player-preference authority. `ValueModel` is a
separate policy module that determines when market price changes that order.

## Tags: stated in overall draft picks

| Draft band | TARGET reach | AVOID clearance |
| --- | ---: | ---: |
| Rounds 1-3 | 6 picks | 12-pick fall below Sleeper ADP |
| Rounds 4-8 | 8 picks | 10-pick fall below Sleeper ADP |
| Rounds 9-18 | 5 picks | 6-pick fall below Sleeper ADP |

If Sleeper ADP is absent, an AVOID does not receive an invented discount: it
is held beneath ordinary source-board values. A player who is the only viable
roster repair can still appear as the labelled fallback.

## VBD and a position run

VBD is projected fantasy points above the position replacement level: QB24,
RB30, WR36, TE16, K12, and DEF12 for this 12-team Superflex roster. It remains
neutral until Sleeper projections are captured for the player and position
peers.

A run is 3 selections at one position in the latest 6 picks, or 5 in the
latest 12. The assistant never chases the count alone: an early pivot needs a
four-point-or-larger VBD cliff from the best remaining option to the fifth.
For DEF, that allows an R16 pivot only when both tests are true; otherwise DEF
stays R17 and K stays R18.

## WR evidence hierarchy

1. The JJ/Late-Round source board is the base.
2. Harmon's WR positional order carries an 8-point score adjustment per source
   board rank of disagreement, heavier than other external overlays.
3. Harmon's rookie Man/Zone/Press composite adds rookie-only evidence.
4. Positive Waldman plus affirmative Harmon evidence is a `STRONG TARGET`.
5. Add a positive JJ tag (`TARGET` or `UPSIDE`) and it becomes a
   `TRIPLE-WINNER TARGET`, with a larger bonus after Round 3.

An analyst's negative or merely neutral rating never satisfies an overlap.
